# Pi Agent Config

Shareable configuration for the Pi coding agent — extensions, skills, and graph output.

## Structure

```
agent/
├── extensions/          # Custom extensions (self-contained, no third-party deps)
│   ├── memory/          # Persistent memory + hybrid search (BM25 + vector)
│   ├── goal/            # Persistent goal tracking
│   ├── context-manager/ # Context window management (ctx_execute, etc.)
│   ├── context-stats/   # Context window usage tracking
│   ├── pi-status/       # Status bar: agent state, tools, compaction
│   ├── safe-guard/      # Destructive command interception
│   ├── pi-mcp/          # MCP bridge extension
│   ├── lib/             # Shared config resolution
│   ├── compaction-offloader.ts  # Offload compaction to local Ollama
│   ├── searxng-search.ts        # Web search via SearXNG
│   ├── web-fetch.ts             # Web fetch tool
│   ├── time.ts                  # Time tools (replaces time MCP)
│   ├── selfcheck.ts             # Infrastructure health checks
│   ├── reasoning-guard.ts       # Reasoning output guard
│   ├── remember.ts              # /remember command
│   └── herdr-agent-state.ts     # Herdr integration (env-gated)
├── skills/              # 26 custom skills (SKILL.md + scripts + examples)
├── MANIFEST.md          # Extension inventory and ownership
├── trust.json           # Trust configuration
├── sentinel-whitelist.json  # Safe command whitelist
└── package.json         # Node dependencies (playwright)

graphify-out/            # Knowledge graph output
├── GRAPH_REPORT.md      # Plain-language architecture report
├── graph.json           # Graph data (god nodes, communities, edges)
├── manifest.json        # Graph manifest
├── cost.json            # Graph costs
└── cache/               # AST and semantic caches

lessons/                 # Lessons learned from agent work
```

## Setup on a New Device

### 1. Clone this repo

```bash
git clone <this-repo> ~/.pi-agent-config
```

### 2. Copy extensions and skills

```bash
# Extensions
cp -r ~/.pi-agent-config/agent/extensions/* ~/.pi/agent/extensions/

# Skills
cp -r ~/.pi-agent-config/agent/skills/* ~/.pi/agent/skills/

# Trust config
cp ~/.pi-agent-config/agent/trust.json ~/.pi/agent/trust.json

# Sentinel whitelist
cp ~/.pi-agent-config/agent/sentinel-whitelist.json ~/.pi/agent/sentinel-whitelist.json
```

### 3. Configure device-specific settings

The following files need per-device customization:

**`~/.pi/agent/settings.json`** — Update the `skills` path:
```json
{
  "skills": [
    "~/.pi/agent/skills",       // or wherever you put them
    "/Users/binh/.pi/agent/skills"  // your device path
  ]
}
```

**`~/.pi/agent/custom-config.json`** — Update URLs for your local services:
```json
{
  "searxngUrl": "http://<your-searxng-host>:8888",
  "offloadProvider": "ollama",
  "offloadUrl": "http://127.0.0.1:11434/v1/chat/completions",
  "offloadModel": "gemma4:e4b",
  "offloadKeepAlive": "1h",
  "embeddingsUrl": "http://127.0.0.1:11434/api/embeddings",
  "embeddingsModel": "nomic-embed-text"
}
```

**`~/.pi/agent/mcp.json`** — Update paths for your local tools:
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "<your-workspace-path>"]
    },
    "context7": {
      "command": "<your-context7-path>",
      "args": [],
      "directTools": true
    },
    "git": {
      "command": "<your-uvx-or-git-path>",
      "args": ["mcp-server-git", "--repository", "<your-workspace-path>"]
    },
    "playwright": {
      "command": "<your-playwright-mcp-path>",
      "args": ["--browser", "chromium"]
    }
  }
}
```

## Extensions

All extensions are self-contained TypeScript with no third-party runtime dependencies (except what Pi provides). See `agent/MANIFEST.md` for full inventory.

### Key extensions

| Extension | Purpose |
|-----------|---------|
| `memory/` | Persistent memory with hybrid search (BM25 + vector embeddings) |
| `context-manager/` | Context window sandboxing (ctx_execute, ctx_index, ctx_search) |
| `context-stats/` | Context window usage tracking and display |
| `safe-guard/` | Destructive command interception |
| `pi-status/` | Status bar with agent state, tools, compaction info |
| `goal/` | Persistent goal tracking |
| `searxng-search.ts` | Web search via SearXNG |
| `compaction-offloader.ts` | Offload compaction to local Ollama |
| `web-fetch.ts` | Web fetch tool |
| `selfcheck.ts` | Infrastructure health probes |

## Skills

26 custom skills covering: code quality, security, frontend design, project management, research, and more.

## Graph

The `graphify-out/` directory contains a knowledge graph of the agent config itself, generated by the graphify skill. This is informational and can be regenerated on any device.

## What's NOT included

These are device-specific or regeneratable and should be managed per-device:

- `~/.pi/agent/sessions/` — Session logs (140MB+)
- `~/.pi/agent/node_modules/` — Node dependencies
- `~/.pi/agent/observability/` — Runtime observability data
- `~/.pi/agent/mcp-cache.json` — MCP cache
- `~/.pi/agent/auth.json` — Authentication tokens
- `~/.pi/agent/memory/` — Device-specific memory database
- `~/.pi/agent/models.json` — Model configuration (device-specific)
- `~/.pi/agent/models-store.json` — Model state (regeneratable)
